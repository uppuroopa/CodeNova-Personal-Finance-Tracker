# Personal Finance Tracker

## Overview
A Java console application for recording income and expenses, tracking balances, filtering transactions, and exporting financial reports.

## Features
- Record income and expenses.
- Store transaction amounts using `BigDecimal` for accurate monetary calculations.
- Record transaction timestamps, categories, and remarks.
- View all transactions.
- Calculate monthly income, expenses, and balance.
- Filter transactions by date range and category.
- Save and load transactions from a CSV data file.
- Export transaction reports to CSV.

## Technologies Used
- Java
- Java Collections
- BigDecimal for monetary precision
- LocalDateTime for timestamps
- CSV file handling

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open a terminal in the project directory.
4. Compile the source files:

   `javac Main.java Transaction.java`

5. Run the application:

   `java Main`

## Usage
Follow the numbered menu to add income or expenses, view transactions, generate a monthly summary, filter records, export reports, or exit the application.

## Files
- `Main.java` — menu, transaction management, summaries, filtering, and file operations.
- `Transaction.java` — transaction data model.
- `transactions.csv` — saved transaction data, generated by the application.
- `finance_report.csv` — exported report, generated by the application.

## Monetary Precision
The application uses Java's `BigDecimal` instead of floating-point types for monetary calculations to avoid common floating-point rounding errors.
